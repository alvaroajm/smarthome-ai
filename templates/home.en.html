Every connection has its place.

Connections let devices talk to each other. You do not need to learn them all at once.

Zigbee

A mesh network common in sensors, bulbs and buttons. Uses a compatible coordinator.

Thread + Matter

Matter helps different brands work together. Devices using Thread also need a compatible Thread hub.
